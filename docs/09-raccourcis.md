## Boutique d'applis

> **Logiciels** (dans la grille `Windows` + `A`) : la boutique d'applis, comme le Microsoft Store. Elle installe des applis **Flatpak** depuis Flathub, isolées du reste du système. Les mises à jour d'Arch ne passent pas par elle : elles restent avec `yay` (pastille de mises à jour de la barre).

| Je veux… | Dans Logiciels | Dans un terminal |
|---|---|---|
| Installer une appli | Rechercher (loupe en haut) → l'appli → **Installer** | `flatpak install flathub nom` |
| Trouver le nom exact d'une appli | | `flatpak search mot` (colonne « ID ») |
| Mettre à jour mes applis | Onglet **Mises à jour** → **Tout mettre à jour** | `flatpak update` |
| Voir mes applis installées | Onglet **Installées** | `flatpak list --app` |
| Désinstaller une appli | Onglet **Installées** → **Désinstaller** | `flatpak uninstall nom` |
| Libérer la place (bibliothèques inutiles) | | `flatpak uninstall --unused` |
| Mettre à jour Arch (pas la boutique) | | `yay` |

> Une appli installée apparaît dans la grille (`Windows` + `A`) et dans le menu (`Windows`). Si elle n'y est pas tout de suite, rouvre la grille.

## Wi-Fi Ynov

> Réseau **WiFi@YNOV** (WPA2 Entreprise). Le mot de passe n'est écrit dans aucun fichier : il est gardé dans le trousseau, ouvert avec ta session. Connexion automatique en arrivant à Ynov, prioritaire sur le partage iPhone.

| Je veux… | Commande (dans un terminal) |
|---|---|
| Me reconnecter | `nmcli connection up "WiFi@YNOV"` (ou icône Wi-Fi de la barre → WiFi@YNOV) |
| Retaper mon mot de passe (changé, ou oublié par le trousseau) | `nmcli connection up "WiFi@YNOV" --ask` |
| Changer d'identifiant Ynov | `nmcli connection modify "WiFi@YNOV" 802-1x.identity "mon.identifiant"` |
| Vérifier qu'Internet marche | `ping -c 3 archlinux.org` |
| Voir sur quel réseau je suis | `nmcli connection show --active` |
| Repasser sur l'iPhone | `nmcli connection up iPhone` |

> Sécurité : PEAP + MSCHAPv2, et le certificat du serveur est vérifié (il doit s'appeler `radius.auvence.co` et être signé par une autorité reconnue). Si un jour ça ne se connecte plus alors que tes camarades y arrivent, Ynov a peut-être changé de serveur : demande le nouveau nom au service informatique, puis `nmcli connection modify "WiFi@YNOV" 802-1x.domain-suffix-match "nouveau.nom"`.

> VDI@YNOV et WiFi@IOT ne sont pas configurés (pas utiles pour ton PC).
